# Исходные материалы

Сюда складываются PDF, скриншоты, конспекты, выписки — всё, что собрано по теме.

**Содержимое этой папки не попадает в git** (кроме этого файла): там чужие
защищённые материалы, им не место в публичном репозитории.

Порядок работы с ними — в `../PLAN.md`, раздел «Правовая рамка». Коротко:
источник разбирается, факт из него переформулируется с нуля, строка заносится
в `../SOURCES.md`. Копипаста нет ни при каких условиях.

Подпапки по темам:

```
source/
├── osanka/       осанка, стопы, таз, позвоночник
├── pitanie/      белок, нутриенты, анализы
├── lico/         мышцы лица, кожа, уход
└── raznoe/
```

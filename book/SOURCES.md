# Реестр источников

**Статус:**
- `факт` — берём только факт или цифру, формулируем с нуля
- `ссылка` — упоминаем в списке литературы, текст не заимствуем
- `не использовать` — чужой брендированный продукт или защищённая методика
- `не по теме` — к книге отношения не имеет

## Итог по партии 1

**Все 18 профильных файлов — чужие коммерческие продукты.** Лид-магниты, уроки
с закрытых платформ, гайды под конкретные курсы. Собственных заметок в архиве нет.

Прямо использовать нельзя ничего. В книгу уходят три факта: механика и
противопоказания МФР, принцип расчёта белка через сухую массу, норма клетчатки
по ВОЗ. Всё это — учебный уровень, оно и так общедоступно.

**Два наблюдения, которые дороже содержимого:**

1. Один и тот же гайд по МФР продают под двумя разными брендами — файл ходит
   по рынку как белая этикетка. Уровень «экспертности» в нише понятен.
2. Архив бьётся ровно на три несвязанные кучи: тело отдельно, питание отдельно,
   лицо отдельно. **Ни один автор не соединяет осанку с овалом лица.** Это и есть
   свободное место, которое занимает наша книга.

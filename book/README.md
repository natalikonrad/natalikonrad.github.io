# «Красота изнутри» — книга

Исходники и сборка PDF-книги Veniva.

```
book/
├── PLAN.md              структура книги, позиционирование, правовая рамка
├── SOURCES.md           реестр источников из архива
├── book.config.json     название, подзаголовок, автор, части
├── content/             главы в Markdown — здесь пишется книга
├── source/              сюда складываются исходные материалы (в git не идут)
├── build/               сборщик: build.mjs + book.css
└── dist/                готовый PDF
```

## Сборка

```bash
cd book/build
npm install          # один раз
node build.mjs       # → book/dist/krasota-iznutri.pdf
node build.mjs --html  # плюс промежуточный HTML для отладки вёрстки
```

Нужен Chromium. В этой среде он уже стоит; на другой машине задай путь:
`CHROME_PATH=/path/to/chrome node build.mjs`.

## Как устроена глава

Файл в `content/`, имя с числовым префиксом — по нему идёт сортировка.

```markdown
---
part: I                      # id части из book.config.json
number: 2                    # номер главы (для оглавления)
kicker: Глава 2              # надзаголовок на шмуцтитуле главы
toc: Найди свой тип осанки   # строка в оглавлении
---

# Найди свой тип осанки

Текст главы…
```

## Врезки

Три вида, оформляются фенсами:

```markdown
::: note
Важное уточнение, дисклеймер, предупреждение.
:::

::: practice
Что делать руками. Тёмный блок, самый заметный на развороте.
:::

::: personal
Место под личную историю. Рамка пунктиром — видно, что черновик.
:::
```

## Вёрстка

- A5, 148×210 мм
- Cormorant — заголовки, буквица, цитаты; DM Sans — текст
- бумага `#FAF7F2`, текст `#1A1614`, золото `#B5A080`, обложка `#151210`
- шрифты вшиваются в PDF в base64 — файл открывается одинаково везде

Правки вёрстки — в `build/book.css`. Структура страниц — в `build/build.mjs`.

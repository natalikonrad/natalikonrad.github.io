# Список анализов

Список для разговора с врачом. Не инструкция к самолечению — интерпретация,
назначения и дозировки за специалистом.

## Базовый набор

| Анализ | Зачем смотрим | На что обратить внимание |
|---|---|---|
| Общий анализ крови | Отправная точка, анемия и её тип | Гемоглобин, эритроциты, их средний объём |
| **Ферритин** | Запасы железа | Гемоглобин падает последним — нормальный гемоглобин дефицит не исключает |
| С-реактивный белок | Воспаление | Смотреть вместе с ферритином: воспаление его завышает |
| Витамин D (25-ОН) | Дефицит в северных широтах — правило, не исключение | С октября по март синтез в коже практически не идёт |
| Витамин B12 | Нервная система, кроветворение | Особенно при малом количестве животных продуктов |
| Фолиевая кислота | В паре с B12 | |
| ТТГ | Щитовидная железа | При отклонении — свободный Т4 и антитела к ТПО |
| Глюкоза натощак | Углеводный обмен | По показаниям — гликированный гемоглобин |
| Липидный профиль | Раз в несколько лет | |

## Как сдавать

- Утром натощак, если лаборатория не указала иначе.
- **Не** в первые дни после обильной менструации — картина по железу будет смазана.
- **Не** на фоне простуды или обострения: воспаление искажает ферритин и СРБ.
- Сообщить врачу обо всех добавках. Биотин искажает результаты по щитовидной
  железе в ряде тест-систем — его отменяют за несколько дней.

## Симптомы, при которых стоит сдать не откладывая

| Что беспокоит | Куда смотреть в первую очередь |
|---|---|
| Выпадение волос, ломкие ногти | Ферритин, ТТГ, витамин D, белок в рационе |
| Усталость без причины, одышка на лестнице | Ферритин, общий анализ крови, ТТГ |
| Сухая кожа, отёчность лица, зябкость, прибавка веса | ТТГ, свободный Т4 |
| Плохое заживление, тусклая кожа | Белок, ферритин, витамин D |
| Постоянная сонливость зимой | Витамин D, ферритин |

## Три правила

1. **Не назначать себе добавки по интернету.** Витамин D накапливается и в
   высоких дозах токсичен. Железо без подтверждённого дефицита вредно.
2. **Не лечить цифру — искать причину.** Низкий ферритин это симптом, а не диагноз.
3. **Читать в комплексе.** Референсы разнятся между лабораториями, показатели
   значат разное в разном контексте.

## Чего в списке нет

Расширенных гормональных панелей без показаний, тестов на пищевую
непереносимость по IgG, анализа волос на микроэлементы, «диагностики
зашлакованности организма». Первое избыточно, остальное не имеет доказанной
диагностической ценности.
